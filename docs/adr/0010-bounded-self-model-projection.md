# ADR 0010: Bounded self-model projection

- Status: Accepted
- Date: 2026-09-12

The companion's self model is initially projected from authoritative local cognition state rather
than generated by the model. It contains at most four natural-language facts, beliefs, values or
change observations per response. Raw trait values are never exposed, and the model cannot persist
self facts directly. Future self records will require Episode or message evidence before persistence.
